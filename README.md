# java-duke

Java 是一门**跨平台、纯粹面向对象**的通用高级编程语言。它结合了“一次编写，到处运行”的平台独立性与强大的自动内存管理机制，常用于开发需要高稳定性、高扩展性和高安全性的软件，例如企业级后台系统、大数据处理、Android 移动应用以及云计算微服务等。

## 核心特点

* **平台无关性：** 核心特征是 **“一次编写，到处运行”（Write Once, Run Anywhere）**。源码被编译为通用的字节码（`.class` 文件），由不同操作系统上的 **Java 虚拟机（JVM）** 解释执行，从而脱离了对底层硬件的直接依赖。
* **纯粹的面向对象：** 相比 C++，Java 是一门**更彻底的面向对象语言**（除基本数据类型外，一切皆对象）。它同样支持封装、继承和多态，但去除了容易出错的指针操作和多继承（改用接口 `interface` 实现），使得代码结构更安全、更规范。
* **自动化内存管理：** 引入了强大的**垃圾回收机制（GC, Garbage Collection）**。开发者无需手动申请和手动释放内存，JVM 会自动追踪并回收不再使用的对象内存，极大地减少了内存泄漏和野指针带来的系统崩溃风险。
* **健壮性与健壮生态：** 具备极高的安全性、内置的多线程并发支持，以及**极其庞大且成熟的开源生态（如 Spring 框架、Maven 生态）**。这使得它在处理高并发、高可用的企业级分布式系统和金融级业务时，拥有极强的稳定性和代码复用能力。
